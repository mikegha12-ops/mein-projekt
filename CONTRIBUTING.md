# Mitmachen

Danke, dass du helfen willst!

1. Forke das Repository und erstelle einen Branch (`git checkout -b mein-feature`).
2. Schreibe deine Änderung und passende Tests in `test_repo_check.py`.
3. Führe `pytest` aus, alle Tests müssen bestehen.
4. Öffne einen Pull Request und beschreibe kurz, was du geändert hast.

Bugs und Ideen gern als Issue melden.
